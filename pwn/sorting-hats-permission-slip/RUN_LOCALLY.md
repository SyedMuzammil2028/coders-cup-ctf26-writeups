# Run locally — The Sorting Hat's Permission Slip

Start with `CHALLENGE.md`, then try the challenge before reading `WRITEUP.md`.

## Start the local service

Open `source/dist` and run:

```sh
docker compose up --build
```

If the application expects a flag, use a local value such as `ACM{local_demo_flag}`.
