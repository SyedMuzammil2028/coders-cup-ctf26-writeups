## Original challenge statement

This is a white-box PWN challenge. Download the provided package to inspect
the code and run its local practice container; its local flag is intentionally
fake. Start your private instance for the real team-specific flag.

Find the shelf that lets you update the restricted passcode, then submit the
resulting flag in the format `ACM{...}`.
